# TOOLS.md - Notes Locales

Les compétences définissent _comment_ les outils fonctionnent. Ce fichier est pour _vos_ spécificités — les choses uniques à votre configuration.

## Ce Qui Va Ici

Des choses comme :

- Noms et emplacements des caméras
- Hôtes SSH et alias
- Voix préférées pour TTS
- Noms d'enceintes/pièces
- Surnoms d'appareils
- Tout ce qui est spécifique à l'environnement

## Exemples

```markdown
### Caméras

- living-room → Zone principale, angle large 180°
- front-door → Entrée, déclenchée par mouvement

### SSH

- home-server → 192.168.1.100, utilisateur : admin

### TTS

- Voix préférée : "Nova" (chaude, légèrement britannique)
- Enceinte par défaut : HomePod Cuisine
```

## Pourquoi Séparer ?

Les compétences sont partagées. Votre configuration est la vôtre. Les garder séparées signifie que vous pouvez mettre à jour les compétences sans perdre vos notes, et partager les compétences sans révéler votre infrastructure.
